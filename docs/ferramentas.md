# Ferramentas

Situação Cadastral expõe 1 ferramenta (todas somente leitura).

### 1. `situacao_cadastral_cpf`
**Input**: `cpf`, `birthdate`

Consulta a situação cadastral de um CPF (nome, situação, data de nascimento, data de inscrição e indicação de óbito).

## Prompts de exemplo

```
Qual a situação cadastral do CPF 000.000.000-00?
Esse CPF está regular na Receita?
Qual meu saldo de créditos?
```
